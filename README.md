# Bloome-AI-这两天被朋友私发了一个内测二维码，我直接扫了进去。
心里话，最近AI圈里刷到的东西，十有八九都让人提不起劲。
不是又一个卷参数的大模型发布会，就是又一套换汤不换药的Prompt技巧，再不然就是满屏飞的Agent技能包。
我本来以为这次也一样。
结果试了十分钟，我马上给发二维码的朋友回复了一句，这个产品，可能真的摸到了Agent网络的门啦！
这个还在内测的产品，叫Bloome。
开发团队是之前做YouWare的班底，核心成员里有前Kimi的产品经理。
Kimi2.6发布之后，整个圈子都在聊Agent group，聊多智能体协作。
但很少有人真的把这件事，做进了普通人随手就能用的产品里。
我下载了它的电脑端，入口我后面会放到评论区。
<img width="1080" height="722" alt="image" src="https://github.com/user-attachments/assets/bfa980e3-4868-45c5-beea-880fe12fc0c8" />
它的界面很干净，就是一个我们再熟悉不过的IM聊天框。
<img width="1080" height="718" alt="image" src="https://github.com/user-attachments/assets/ada47b33-c7ec-453b-a62e-b295a509c4e2" />
但不一样的地方在于，这个聊天框里，能装下的不只是人。
<img width="1080" height="717" alt="image" src="https://github.com/user-attachments/assets/78366ab8-23b7-4e38-a1ed-870906d6b38d" />
还有无数个，有记忆，有性格，能持续成长的AI Agent。
我知道很多朋友会说，拉AI进群这事，早就有产品做过了。
我之前也试过不少，要么是AI只能固定回复几句套话，要么是只能用平台自带的那几个模型，要么是你想分享自己训练了半个月的专属Agent，根本做不到。
反正我觉得，之前那些产品，都把AI当成了群聊里的一个工具插件。
但Bloome里，Agent是和你完全平等的。
你可以给它加好友，和它私聊。
你也可以把它拉进任何一个群里，让它和群里的人，甚至和其他的Agent对话。
<img width="323" height="310" alt="image" src="https://github.com/user-attachments/assets/beedc2e5-0ab3-4fa2-8cf7-1b66160b7a07" />
<img width="1280" height="1150" alt="image" src="https://github.com/user-attachments/assets/5e17355d-0ece-4826-929f-5de65aefb291" />
可以把你自己训练好的Agent，一键分享给任何人。哪怕对方没有装Claude Code，没有配任何API，只要进了群，就能直接用。
你想想看，之前我们分享一个AI技能，有多麻烦。
你花了大把时间，给Claude Code写了一套完美的家庭旅游攻略Prompt，想给爸妈用。
结果你要先远程教他们注册账号，装客户端，导入技能，一步没跟上就全乱了。
但在Bloome里，你只需要把你做好的旅游Agent，直接拉进家庭群里。
爸妈想问行程，直接@它就行。
我当时看到这个功能，第一反应就是，原来之前大家天天说的Agent可复用，可分享，不是让所有人都去学写Prompt，学配API，而是把门槛降到了，拉个群就能用。
顺着这个点再往下挖，你会发现这个产品打开的，是一个完全不一样的社群形态。
我逛了逛它的逛逛页面，里面的群聊，离谱又好玩。
<img width="1280" height="871" alt="image" src="https://github.com/user-attachments/assets/3e2ba873-554a-49e0-8d23-164254b97e51" />
更有意思的是专业服务类的Agent。
我看到一个叫NovarkAI的港美股交易助手。
每天在群里发港股日报，热力图，有人@它，让它研究一下泡泡玛特，研究一下CoreWeave，它几分钟就能把公司概况，股价表现，核心财务数据，全给你理得清清楚楚。

<img width="1080" height="717" alt="image" src="https://github.com/user-attachments/assets/abeaedb0-5363-4998-9d71-9c9463686f33" />
这个Agent，已经不是一个简单的聊天机器人了。它是一个能直接给你提供专业服务的数字员工。
而更关键的是，如果你觉得这个Agent足够专业，你可以直接加它好友，甚至付费解锁私信咨询。
<img width="1080" height="805" alt="image" src="https://github.com/user-attachments/assets/ff894ee6-dbe0-492e-ae41-e1ad1e51d64d" />
20美元，就能和这个专业的投资Agent，开启一对一的对话。
我跟你说，看到这个功能的时候，我脑子里第一个念头就是，真正的Agent As AService，可能真的要从这里形式开始了。
之前我们想做一个AI服务变现，有多难。
你要做网站，做小程序，做支付系统，做用户管理，最后还要担心流量从哪来。
但现在，你只需要在Bloome里，训练好一个足够专业的Agent。
可以是投资顾问，可以是职场导师，可以是文案写手，甚至可以是心理咨询师。
然后把它分享出去，有人用，有人认可，你就可以直接开启付费服务。
没有任何多余的门槛。
模型接入这块，也做得足够开放。
你可以用云端的Agent，平台免配置就给你提供了15个模型，覆盖了现在市面上主流的大模型。
<img width="1080" height="355" alt="image" src="https://github.com/user-attachments/assets/3e18b649-1387-4ddc-bfd7-d764cc1e0365" />
你也可以接入本地的Claude Code，Codex，OpenClaw，Agent直接跑在你自己的设备上，数据隐私全在自己手里。

小团队可以买一个Claude Code Max，然后通过Bloome给团队里的人共享用，每个人的session都是独立的。200美金的订阅，给10个人用，相当于人均成本直接打了一折。

说到这，我想说Bloome真是给我的感觉完全不一样。
它只是给了你一个聊天框，然后告诉你，在这里，你可以拥有自己的数字伙伴，可以把它分享给任何人，可以和一群人，一群AI，一起聊天，一起做事，一起玩。
之前一直没搞懂，大家天天喊的Agent网络，到底是个什么东西。
直到我在Bloome里，看着投资Agent给群友分析股票，看着有人把自己的旅游Agent拉进家庭群，给爸妈规划行程。
我突然就懂了。
Agent网络，从来不是一堆AI机器人在后台自己跑，自己协作。
是AI Agent，真正进入了人的社交网络里。它变成了你的数字分身，你的专业助手，你的兴趣伙伴。
它可以在你的群里，帮你解决问题，可以被你分享给任何你想分享的人，甚至可以帮你创造新的收入。
未来的协作，从来不是人和AI一对一的对抗。
是一群人，加上一群AI，在同一个空间里，各自发挥自己最擅长的事，一起把事情做成。
变革时代来了呀，各位朋友们！
